Personal Portfolio Website

A clean, modern, and fully responsive portfolio designed to highlight my projects, technical skills, certifications, and extracurricular activities. Built using React.js and Vite to ensure fast performance, smooth animations, and an elegant user experience.
👉 View Live Portfolio https://shravani-2137.vercel.app/

🔧 Tech Stack

React + Vite
HTML
CSS / TailwindCSS
JavaScript

✨ Key Features

Organized Sections: Home, About, Projects, Skills, Certifications, Extracurriculars & Contact
Interactive Project & Certificate Modals: Click to explore detailed views
Responsive Design: Optimized for desktops, tablets, and mobile screens
Contact Form Integration: Send messages directly using EmailJS
Modern UI: Soft pastel theme with smooth transitions and clean layout
